# Фазовый шум и скорость ключа в волоконной QKD — v1.1

[English](README.md) · [Руководство на английском](docs/USER_GUIDE.md) · [Источники](SOURCES.md)

Программа на Python оценивает, как шум лазеров и волокна ограничивает квантовое
распределение ключа. Пользователь задаёт параметры своей установки или
измеренные данные и получает скорость ключа, рабочее окно, доли разных шумов
и оценку того, какое улучшение оборудования даст наибольший выигрыш.

## Задумка

Основа — опубликованная модель [Bertaina et al., 2024](https://doi.org/10.1002/qute.202400032)
и [код авторов](https://doi.org/10.5281/zenodo.10911121). Расчёт TF-QKD связывает:

**Спектры лазеров и волокна → шум фазы в точке интерференции → длительность
сбора ключа → рабочий цикл → скорость ключа SNS-AOPP или CAL.**

Модель воспроизведена и дополнена расчётом классической компенсации с круговым
проходом и задержкой по Williams. Полюс исполнителя и выбор усиления помечены
как инженерные допущения. Сравнение помогает оценить пользу стабилизации и
улучшения оборудования до изменения установки.

Отдельный исследовательский блок mode-pairing считает изменение фазы между
импульсами и асимптотическую оценку ключа Zeng при заданных decoy-данных.
Программа моделирует установку; управление аппаратурой и выработка настоящего
криптографического ключа в неё не входят.

## Возможности

- Ввод коэффициентов, поддерживаемых паспортных величин и измеренных PSD из CSV.
- Расчёт по измеренной остаточной СКО фазы без спектрального прогноза.
- Полные потери каждого плеча и отдельные параметры детекторов; ограничения скалярной протокольной модели указаны в отчёте.
- Сравнение отсутствия стабилизации, классической и двухдиапазонной схем, а также идеального обнуления шума волокна.
- Ранжирование улучшений, обратные требования к незаданным шумам и опциональный расчёт дальности по целевой скорости.
- Командная строка, локальная веб-форма и отчёты Markdown/HTML/JSON с графиками.

Параметры чужой установки не подставляются молча. При неизвестных ошибке
рассогласования или коэффициенте коррекции ошибок результат обозначается как
верхняя оценка. Конфигурации из статей служат примерами.

## Быстрый запуск

После клонирования перейдите в папку репозитория. Нужен Python **3.11+**:

```bash
python -m pip install -r requirements.txt
python -m tfqkd.lab_run examples/laboratory/stabilized_dual.toml --output results/my_run
python -m tfqkd.lab_web --port 8765
```

Веб-форма: http://127.0.0.1:8765. В примерах указаны единицы и источники;
для своей установки замените входные данные.

## Что проверено

- Независимая реализация спектров, интеграла и рабочего окна: расхождение **1,978 × 10⁻⁷**. [Числа](results/stage3_d/independent.json)
- Быстрая сетка **4 097** точек против эталонных **65 537**: погрешность дисперсии **5,101 × 10⁻⁵** при допуске **10⁻⁴**. [Регрессия](results/stage3_a/grid_regression.json)
- Zhou TF: калибровка одного параметра на одной длине предсказывает другую с ошибкой **8–11%**, эквивалентной примерно **4 км** при явно принятой интерполяции потерь. Это проверка протокола и потерь с калибровкой, не спектральной модели. [Сравнение](results/out_of_sample/details.md)
- На краю дальности, **615,59 км**, модель даёт ноль против опубликованных **0,32 бит/с**. Поправочный множитель не введён.
- Mode-pairing: проверен переход спектра в модель дрейфа. Коэффициенты другой линии дают дрейф в **1,6–2,8 раза** выше опубликованного; закон независимых участков не входит в условный 95% интервал подгонки для катушек. [Анализ](results/mp_spatial_analysis/details.md)

В проверенных сценариях Bertaina классическая компенсация практически теряет
выигрыш около **30–70 км на плечо**, а двухдиапазонная реализует большую часть
идеального потолка. Граница зависит от входных параметров и не является
универсальным пределом. [Результаты](results/release_v1_0/conclusion_checks.json)

## Ограничения

Ключ считается асимптотически, без конечного размера выборки. В классической
схеме не учтён шум измерения фазы; исполнитель описан одним полюсом. Модель
линии не воспроизводит полную форму измеренного спектра 114 км. Для
mode-pairing аналитические decoy-границы иногда дают ноль при положительном
экспериментальном ключе. Дрейф лабораторных катушек нельзя считать параметром
полевой линии. [Полный перечень](docs/UNKNOWNS.md)
